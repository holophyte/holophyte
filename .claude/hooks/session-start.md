## Available Workflow Skills

- `/brainstorm` — Design gate before implementation. Use for architecturally complex features (new data models, system boundaries, multiple valid approaches).
- `/autopilot` — Implement a feature end-to-end with PR review iteration.
- `/autopilot-team` — Parallel agent team for complex multi-file features.
- `critic` agent — Adversarial reviewer for plans and implementations. Spawn for a second opinion.
- `/simplify` — Clean up code for quality, duplication, and simplification. Runs automatically in autopilot workflows; invoke standalone for targeted cleanup.

Consider `/brainstorm` before non-trivial implementation.
