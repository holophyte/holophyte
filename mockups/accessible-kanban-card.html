Key Accessible Patterns Used

WCAG 2.5.7 — Dragging Alternative

Action menu button on each card provides keyboard-accessible "Move to" and "Reorder" options, eliminating the requirement for mouse-based drag-and-drop.

WCAG 1.4.1 — Use of Color

All status indicators pair color with icon and text. Priority uses directional arrows (⏫ ↑ — ↓) that convey urgency even without color perception.

WCAG 4.1.3 — Status Messages

Session status uses role="status" so screen readers announce changes. Move actions trigger aria-live="polite" announcements.

WCAG 2.5.8 — Target Size

Action menu button is 24x24px minimum. All interactive elements meet the 24px target size requirement from WCAG 2.2 Level AA.
