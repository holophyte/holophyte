I found the issue. The returnTo parameter is set during the initial redirect but gets lost because it's stored in a cookie that expires during the OAuth roundtrip. The fix involves:

1. Storing the return URL in the OAuth state parameter instead of a cookie
2. Extracting it from the callback's state query parameter
3. Using it as the final redirect target

✏️ Edit — src/server/auth.ts
// Before: returnTo stored in cookie (expires during OAuth roundtrip) // After: returnTo encoded in OAuth state parameter const state = encodeOAuthState({ returnTo: req.query.returnTo ?? '/dashboard' }); const authUrl = `${GITHUB_AUTH_URL}?state=${state}&...`;
✏️ Edit — src/server/auth.ts (callback handler)
// Extract returnTo from state parameter on callback const { returnTo } = decodeOAuthState(req.query.state); return Response.redirect(returnTo ?? '/dashboard');
