The Presence Engine

Digital body doubling for focus — visible parallel agent activity provides ambient accountability. Notification tiers prevent overwhelm while keeping you informed. Context recovery eliminates re-orientation friction.

🤝 Presence Bar — "Working Together"

Always visible at the bottom of the screen. Shows you and your agents as a team, not as tools. The companion pulse breathes gently — present but not demanding attention.

Body doubling principle: ADHD research shows that having another "presence" while working dramatically improves focus. The Presence Bar reframes agents from "background tools" to "working alongside you." Clicking any item navigates to that task/session. The companion pulse is a subtle breathing animation — present but not distracting.

🔔 Notification Tiers

Four tiers, each independently toggleable. ADHD users can dial down to "Urgent only" during deep focus without missing critical approvals. Default: Urgent + Informative on, Ambient + Digest off.

🚨 Urgent
Approval requests, agent failures, permission errors. Things that block progress.
⚠️
Agent needs approval to run rm -rf node_modules
Delivered: Sound + visual toast + aria-live="assertive"
✅ Informative
Session completions, test results, task movements. Positive progress updates.
✓
Auth tests pass — 12/12 in 3.2s
Delivered: Badge count + aria-live="polite"
💡 Ambient
Agent currently editing files, heartbeat updates, progress ticks. Background awareness only.
📝
Agent 1 is editing src/payment/webhook.ts
Delivered: Presence bar update only (no toast, no sound)
📊 Digest
Periodic summaries on demand. "Today: 5 sessions completed, 1 needs review, $4.20 spent."
📋
Daily summary: 3 tasks completed, 2 in review, $6.40 total cost
Delivered: On-demand only (click bell icon or scheduled email)

🧭 Context Recovery — "Where Was I?"

When a user returns after being away, Holophyte immediately re-orients them. No archaeology needed — one banner tells you the state and offers the next action.

Welcome back! You were reviewing "Fix OAuth redirect". Agent finished 12 minutes ago — 2 files changed, all tests pass.
Context recovery principle: ADHD users lose context frequently. Coming back to a tool after 20 minutes should take <1 second to re-orient. This banner appears on app load if the user has an active task they haven't viewed in >5 minutes. One click to resume.

"What Should I Do Next?"

After a session completes, Holophyte suggests the most logical next action. The primary suggestion is highlighted. Reduces "staring at screen" paralysis.

Activation energy principle: For ADHD users, starting the next action is the hardest part. These buttons eliminate the "what now?" decision. The suggested action is based on task state: if tests haven't run → suggest "Run tests." If all tests pass → suggest "Review diff." If diff is reviewed → suggest "Mark as done."

⏱ Gentle Time Awareness

Time indicators that inform without pressuring. No countdowns. No alarms. No "OVERDUE" screaming.

❌ Don't: Punishing
⚠️ OVERDUE by 3 days!
This task was due March 8. Please complete it immediately.
Triggers shame. Makes the user feel behind. Counterproductive for ADHD.
✅ Do: Gentle
Originally due March 8
Neutral tone. Offers a forward action. No judgment. Just "what do you want to do?"
